## Featured Projects

### [Liminal — Community Operations Platform](https://github.com/christopheralagna/Liminal-Website-Revision)

A full-stack web application and historical archive for Liminal Community Center & Cafe, a nonprofit community space I co-founded and directed.

The application includes volunteer management, shift scheduling, role-based access control, and an operational dashboard. It uses a relational database and automated testing to support reliable administrative workflows.

**Technologies:** Next.js, React, TypeScript, PostgreSQL, Prisma, Better Auth, Tailwind CSS, Vitest, Docker

### [Chord Kaleidoscope — Generative Harmony Instrument](https://github.com/christopheralagna/Chord-Kaleidoscope)

An independently developed and commercially released Max for Live device that generates real-time harmonic accompaniment from incoming MIDI.

Combines live harmonic-context tracking, configurable chord generation, interactive visualization, and multiple rhythmic trigger modes. Designed for improvisation, composition, and experimental sound design.

**Technologies:** Max for Live, Max/MSP, MIDI, generative algorithms, interactive interface design
